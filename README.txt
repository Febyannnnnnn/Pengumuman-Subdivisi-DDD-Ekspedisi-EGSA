DDD Ekspedisi EGSA 2027 — Paper-cut announcement site

Files to upload into the existing GitHub repository root:
- index.html
- style.css
- script.js
- assets/ (whole folder)

The assets are direct crops from the Visual Guideline image supplied in chat.
Names and subdivisions are configured at the top of script.js.
Audio uses Web Audio API and is triggered by the user's submit action, avoiding external MP3 links.
Google Fonts are loaded online; if unavailable, fallback fonts are used.
